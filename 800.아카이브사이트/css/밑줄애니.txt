[밑줄애니]
-> 오버시 왼쪽에서 들어와서
아웃시 오른쪽으로 밑줄이나가는 애니





/* 링크박스 a요소 */
.link-box a{
  /* 가상요소 자식이 block이므로 최소한
  display를 inline-block으로 해야 자신의
  크기만큼 크기를 가지게 된다.

  ->inline내부의 block은 inline부모를 무시하고
  바깥박스를 기준하여 끝까지 width를 차지한다*/
  font-size: 24px;
  line-height: 37px;
  display: inline-block;
}
.link-box a::after{
  content: '';
  display: block;
  /* 처음에 가로크기 0(돌아올때) */
  width: 0%;
  /* 마진값으로 돌아올때 오른쪽으로 나가는것처럼 보이게하기 */
  margin-left: 100%;
  /* 마진값의 퍼센트는 부모박스(a요소)의 가로크기이다. */
  height: 2px;
  background-color: red;
  /* 트랜지션 trs */
  transition: .3s linear;
}
/* a에 오버시 가상요소 밑줄 글씨만큼 나오게 */
.link-box a:hover::after{
  /* 처음에 가로크기 0 */
  width: 100%;
  /* 왼쪽마진값은 오버시 0이 되어야하고
  애니메이션 처리하지 말아야함 따라서
  transition 속성값을 width로 써서 처리할것 */
  margin-left: 0;
  transition: width .3s linear;
}
